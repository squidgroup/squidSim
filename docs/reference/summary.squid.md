# summary.squid

summary method for class 'squid'

## Usage

``` r
# S3 method for class 'squid'
summary(object, ...)
```

## Arguments

- object:

  an R object of class 'squid'

- ...:

  further arguments passed to or from other methods.

## Value

A list, printed as a side effect, with the number of populations,
observations and responses, and the sampling type.
