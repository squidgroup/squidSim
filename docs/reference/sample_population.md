# sample_population

Sample population level data

## Usage

``` r
sample_population(x, type, param, plot = FALSE)
```

## Arguments

- x:

  A squid object, created using simulate_population().

- type:

  Type of sampling, needs to be one of 'nested', 'missing' or temporal.
  See details.

- param:

  A set of parameters, specific to the sampling type. See details.

- plot:

  Logical. Should illustrative plots be made - defaults to FALSE.
